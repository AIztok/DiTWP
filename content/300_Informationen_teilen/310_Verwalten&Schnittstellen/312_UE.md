## Anwendung 3D Viewer

Um das geometrische Modell mit anderen zu teilen gibt es mehrere Wege:
- die Grasshopper Geometrie wird "gebacken" - umgeformt in die Rhino Geometrie
- über eine Komponente - in unseren Fall von TT-Toolbox (siehe [[012_Rhino_3D#TT-Toolbox]])
- über Speckle

Wir gehen zurück in das Modell aus der [[112_UE]] und wählen den Datencontainer mit den zwei BREPs (Decke und Wand) aus.

### Bake
- Rechtclick auf den Datencontainer der BREPs und Bake

![[312_UE_Bake_1.png]]

 Bestätigen die Layer:
![[312_UE_Bake_2.png|300]]

![[312_UE_Bake_3.png]]

### Visualisierung des Modells lokal

Es gibt mehrere Anbieter die 3D Modell über Browser visualisieren können. Einer von denen ist:
https://3dviewer.net/

Das Modell kann jetzt direkt geöffnet werden. Und ggf. auch in anderen Formaten gespeichert werden.

![[312_UE_3dviewer.png]]

### Visualisierung des Modells online

Wenn das Modell gerne online geteilt werden will, dann muss es gehostet werden.
Einfacherweise kann hier Github (ein Account ist erforderlich) verwendet werden.

Dafür muss nur das File hochgeladen werden:

![[312_UE_3D-Modell_3d_Viewer_github_2.png]]

![[312_UE_3D-Modell_3d_Viewer_github_1.png]]

Danach wählt man das File im Github und kopiert einfach den Pfad im Browser, in unseren Fall:

https://github.com/AIztok/DiTWP_Data/blob/main/312_UE/DiTWP_Model.3dm

Danach muss in 3dviewer das "Open from url" gewählt werden:

![[312_UE_3D-Modell_3d_Viewer_github_3.png|300]]

Hier wird der Link einkopiert und mit OK bestätigt:

![[312_UE_3D-Modell_3d_Viewer_github_4.png|300]]

Es öffnet sich das Modell und dieses kann dann weiter geteilt werden:

![[312_UE_3D-Modell_3d_Viewer_github_6.png]]

Entweder als Link oder Embedding (zum visualisieren auf einer Internet Seite) wie unten:
